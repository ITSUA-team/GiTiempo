- **Close target:** frame roots show38x38close control; implementation uses44x44with16pxbrand icon and radius6. `docs/ui/components.md`,Buttons, requires minimum44x44touch target. This is explicit docs precedence; no PrimeVue limitation is claimed.

The required font,size,weight,color match; semantic H2 typography follows `docs/ui/components.md`. Intrinsic browser text wrapping/line boxes are measured in JSON, not claimed pixel-identical.
