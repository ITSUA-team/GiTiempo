## Admin authorization follow-up

The focus refresh reads the current profile and workspace memberships together and commits them only while its request version and access token are still current. A demotion clears wider cached queries before leaving the protected view. Unchanged roles invalidate active queries to reconcile changed project assignments. Read failure clears protected profile/membership/cache state while retaining the session, shows the existing error toast, and allows a later focus refresh to recover. Store regressions cover overlapping memberships/profile/workspace names, stale success, stale failure and failure/retry recovery; App integration covers demotion redirection, toast feedback and focus-listener cleanup.
