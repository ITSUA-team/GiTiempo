# #527 · Повторна звірка інвойсів

Перевірено робочу версію поверх `faeda763` на гілці `feat/527-invoice-enhancements` за [GITiempo.pen](../../../GITiempo.pen), версія `c5180df6`. Нумерація нижче відповідає порядку 42 рядків [початкової звірки](design-parity.md). Знімки нижче зроблено після виправлень. SHA-256 сукупності змінених шляхів і їхнього вмісту в `apps/` та `packages/` — `f41444b676501cc846ac20d46c1dabeb7caedb6457fde9869f056eb2c3224259`. Порівняно також рендери ключових фреймів із JSON дизайну та актуальні екрани.

**Google Chrome for Testing 149.0.7827.55**, вікна **1280 × 900** та **375 × 812**, локальна Admin SPA зі справжнім API, емулятором входу й окремою базою ручного приймання. При горизонтальному розмірі 375 px ширина документа залишалася 375 px. Помилки завантаження навмисно відтворено перериванням локального запиту. Помилки дубліката назви й конфлікту запису повернув API. Розташування списку, налаштування, редактор, деталі та завантаження повторно перевірено також у зібраній версії Admin SPA.

## Перевірка сум

Створено новий інвойс з одним 15-хвилинним записом, ставкою 1,01 USD і знижкою 0%. На desktop і mobile відредаговано склад інвойса, перевірено нульовий попередній розрахунок після зняття вибору та повторно збережено із включеним записом. З кожного вікна завантажено PDF через дію Download PDF.

| Значення | Збережений інвойс | Завантажений PDF |
|---|---:|---:|
| Години | 0,25 | 0,25 |
| Проміжна сума | 0,26 USD | 0,26 USD |
| Знижка 0% | 0,00 USD | 0,00 USD |
| До сплати | **0,26 USD** | **0,26 USD** |

Сервер, деталі й PDF використовують спільну функцію з цілочисловим округленням. Сума знижки на сторінці виводиться з різниці між округленою проміжною та збереженою кінцевою сумами. [Деталі в Chrome](parity-retest/rounding-375.png) · [Файл, завантажений з Chrome](parity-retest/invoice-1280.pdf)

### Контекст, який залишається видимим

Спільна оболонка Admin зберігає навігацію застосунку, включно з нижньою панеллю на mobile. У загальних налаштуваннях залишилися часовий пояс Workspace та картка GitHub Account перед GitHub Workspace Access. Їхню наявність і порядок вимагають [правила Admin SPA](../../../docs/ui/pages-admin.md). У редакторі додаткове меню поряд із Use settings зберігає можливість змінити логотип конкретного інвойса. PDF використовує вбудований шрифт Roboto з підтримкою українського тексту. На багатосторінковому документі фінальний підсумок переноситься після довгих інструкцій або приміток, коли інакше він опинився б на попередній сторінці.
