Verify with a Vitest component test (mock the auth runtime via `setAuthRuntimeForTesting(createRuntimeMock(...))` like `ForgotPasswordView.spec.ts`, real router with memory history, `data-testid` hooks, `waitForRoute`) covering: missing params (panel, no toast), invalid/expired code (panel + error toast with verify logContext), weak password (inline only, no toast), Firebase confirm failure (inline + error toast with confirm logContext), success-redirect-to-login (success toast + redirect), AND assert `expect(globalThis.fetch).not.toHaveBeenCalled()` (no raw password sent to any API) plus assert the submitted password value never appears in any toast `detail`/`summary`, inline `Message` text, or `logContext` passed to `showErrorToast`/the logger.
